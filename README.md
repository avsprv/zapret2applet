# zapret2control

**Графический интерфейс для управления установленной службой [zapret2](https://github.com/bol-van/zapret2) в Linux.**

[English](README.en.md) · **Русский**

Приложение предоставляет графический интерфейс для управления уже установленной службой zapret2, запуска сетевых тестов blockcheck2 и обновления zapret2.

> [!IMPORTANT]
> **Независимый проект.** zapret2applet не связан с автором или сопровождающими [zapret2](https://github.com/bol-van/zapret2).
>
> Приложение не выполняет первоначальную установку zapret2. Найденные стратегии необходимо вручную перенести в конфигурацию zapret2 и проверить.

## Возможности

- **Управление службой:** просмотр состояния, запуск и остановка systemd-службы zapret2.
- **Конфигурация:** просмотр и редактирование `/opt/zapret2/config`, проверка shell-синтаксиса, резервное копирование, атомарное сохранение и откат.
- **Профили:** статический анализ профилей `NFQWS2_OPT`, создание, редактирование, копирование и удаление; безопасное применение изменений.
- **Списки:** просмотр пользовательских хостлистов и производных IP-списков; редактирование трёх исходных пользовательских хостлистов с проверкой записей и резервным копированием.
- **Мониторинг:** просмотр последних записей журнала фиксированной службы `zapret2.service` через read-only действие Polkit.
- **Сетевые тесты:** запуск upstream-скрипта `blockcheck2` для тестирования сетевой доступности указанных пользователем доменов по HTTP, TLS 1.2/1.3 и HTTP/3 (QUIC), с поддержкой IPv4 и IPv6.
- **Результаты:** просмотр и копирование найденной стратегии.
- **Системный трей:** приложение продолжает работать в области уведомлений после закрытия главного окна.
- **Автозапуск:** запуск службы при загрузке системы и приложения при входе пользователя.
- **Обновления:** проверка релизов upstream-проекта и установка zapret2 из интерфейса.
- **Локализация:** русский и английский языки.

## Совместимость и требования

Для сборки требуется **Qt 6.8+**, CMake 3.21+, компилятор C++20 и Ninja. Также необходимы systemd, Polkit, pkexec, curl и tar.

| Дистрибутив | Базовая версия из packaging-конфигурации |
|---|---:|
| Fedora | 41+ |
| Debian | 13 (Trixie)+ |
| Ubuntu | 25.04+ |

Версии отражают базовый уровень доступности Qt 6.8, а не гарантию поддержки каждого выпуска. **Ubuntu 25.04 завершила срок поддержки**: не устанавливайте её только ради этого приложения. Для Ubuntu используйте актуальный поддерживаемый выпуск с Qt 6.8+; конкретный выпуск следует проверять отдельно.

**Чистая установка zapret2 доступна на вкладке «Обновления».** Приложение загружает последний стабильный релиз, проверяет структуру архива и SHA-256 бинарных компонентов, создаёт `/opt/zapret2` и устанавливает systemd unit. Существующие каталоги и unit-файлы не перезаписываются. Первичная конфигурация создаётся с `NFQWS2_ENABLE=0`; служба не запускается и не включается в автозагрузку. Перед запуском необходимо отдельно проверить зависимости, выбрать и настроить firewall и вручную включить нужные параметры в конфигурации. Интерактивный upstream-инсталлятор не запускается.

## Установка

1. Скачайте пакет zapret2applet со страницы [Releases](https://github.com/avsprv/zapret2applet/releases).
2. Установите его:

**Fedora (.rpm):**
```bash
sudo dnf install ./zapret2applet-*.rpm
```

**Debian / Ubuntu (.deb):**
```bash
sudo apt install ./zapret2applet_*.deb
```

3. Запустите zapret2applet из меню приложений. Если zapret2 ещё не установлен, откройте вкладку «Обновления» и выполните чистую установку. Перед запуском службы настройте конфигурацию и зависимости.

Если готовый пакет недоступен, используйте [сборку из исходников](#сборка-из-исходников).

## Использование

### Управление службой

На вкладке **«Статус»** отображается состояние службы zapret2. Здесь можно запустить или остановить службу и настроить её автозапуск. Запуск самого приложения при входе пользователя настраивается отдельно.

### Конфигурация

На вкладке **«Конфигурация»** можно прочитать и отредактировать `/opt/zapret2/config`, проверить shell-синтаксис без исполнения файла, сохранить конфигурацию с резервной копией или откатить последнюю запись. Перед сохранением helper проверяет синтаксис и атомарно заменяет файл. Сервис автоматически не перезапускается.

### Профили

Вкладка **«Профили»** анализирует статическое значение `NFQWS2_OPT` и показывает разделённые через `--new` профили. Можно создавать, изменять, копировать и удалять профили. Редактор не исполняет config, shell-код или Lua. Перед применением helper проверяет shell-синтаксис, создаёт резервную копию и атомарно записывает изменения; сервис автоматически не перезапускается.

### Списки

Вкладка **«Списки»** позволяет просматривать исходные пользовательские хостлисты и производные IP-списки. Редактировать можно только три исходных пользовательских хостлиста; записи проверяются как домены, IP-адреса или CIDR. Производные IP-файлы доступны только для чтения, поскольку zapret2 пересоздаёт их самостоятельно. Перед сохранением создаётся резервная копия.

### Мониторинг журнала

Вкладка **«Мониторинг»** показывает последние 50, 100, 200 или 500 записей журнала фиксированной службы `zapret2.service`. Чтение выполняется через отдельное read-only действие Polkit. Автообновление с интервалом 10 секунд доступно по желанию и выключено по умолчанию.

### Подбор стратегий

1. Укажите домены для проверки.
2. Запустите подбор на соответствующей вкладке.
3. Если служба zapret2 активна, приложение предложит остановить её на время тестирования.
4. Дождитесь завершения и изучите результаты.
5. Скопируйте подходящую стратегию и вручную перенесите её в конфигурацию zapret2.

Проверяются HTTP, TLS 1.2/1.3 и HTTP/3 (QUIC), IPv4 и IPv6. Результат зависит от сети и текущих условий фильтрации; успешный тест не гарантирует постоянную работоспособность стратегии.

Движок поддерживает от 1 до 10 доменов, уровни сканирования veryquick, quick, standard, force и от 1 до 10 повторов. Глубокое сканирование может занять несколько минут.

### Обновления

На вкладке **«Обновления»** можно проверить наличие нового релиза zapret2 и запустить обновление. Автоматическая проверка включена по умолчанию и выполняется не чаще одного раза в сутки; её можно отключить.

## Безопасность

Основной интерфейс работает от имени обычного пользователя. Операции с системными привилегиями выполняет отдельный helper через Polkit и pkexec. Повышение привилегий может потребоваться для управления службой, тестирования стратегий и обновления zapret2.

Helper принимает ограниченный набор операций и проверяет аргументы. При обновлении авторизация запрашивается отдельно, поскольку заменяются файлы, которые затем могут выполняться с правами root.

Файлы релиза zapret2 сверяются с SHA-256 суммами из sha256sum.txt. Это помогает обнаружить повреждение или несоответствие опубликованному списку сумм, но **не является проверкой криптографической подписи релиза** и не защищает от компрометации upstream-репозитория или его учётной записи. Updater проверяет структуру архива и версию, сохраняет резервную копию перед заменой и предусматривает откат при ошибке установки.

## Сборка из исходников

### Зависимости

**Fedora:**
```bash
sudo dnf install cmake ninja-build gcc-c++ qt6-qtbase-devel qt6-qttools-devel polkit
```

**Debian / Ubuntu:**
```bash
sudo apt install build-essential cmake ninja-build qt6-base-dev qt6-tools-dev qt6-l10n-tools pkexec
```

### Сборка и тесты

```bash
git clone https://github.com/avsprv/zapret2applet.git
cd zapret2applet
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
```

Запуск без установки: ./build/zapret2applet.

Установка в систему:
```bash
sudo cmake --install build --prefix /usr
```

При запуске из каталога сборки диалог авторизации может не содержать описания действия, которое появляется после системной установки Polkit policy.
